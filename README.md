# 毎日の自己管理（PWA版）

iPhone の Safari で「ホーム画面に追加」して使う Web アプリです。
元は claude.ai のアーティファクト（https://claude.ai/artifact/6Js1zjtyoiopfS6AxymXaK）で、機能と画面はそのまま引き継いでいます。

## ファイル構成
- `index.html` … アプリ本体（元のアーティファクトに PWA 化・AI 接続・設定・バックアップを追加）
- `manifest.webmanifest` / `icons/` … ホーム画面用の名前・アイコン
- `sw.js` … オフラインで起動するためのキャッシュ
- `vendor/anthropic-sdk-1.5.0.mjs` … Anthropic 公式 TypeScript SDK 1.5.0 をブラウザ用に1ファイルにまとめたもの

## 公開方法（例：GitHub Pages）
1. このフォルダの中身をリポジトリに置いて、GitHub Pages を有効にします（HTTPS が必須です）。
2. iPhone の Safari で公開した URL を開き、共有ボタン →「ホーム画面に追加」を選びます。
3. アプリ下部の「アプリ設定」で Anthropic の API キーを入力し、「接続テスト」を押します。

## データ
- 記録はその iPhone 内（ホーム画面アプリの保存領域）にだけ保存されます。
- Safari で開いた場合とホーム画面アプリで開いた場合は保存領域が別になります。
- 「アプリ設定 → バックアップ」で JSON ファイルの書き出し・読み込みができます（API キーは含みません）。

## AI 機能
- 写真の栄養分析、オムロン画面の読み取り、トレーナーの総評、今日の気づきに Claude API を使います。
- API キーは端末内に保存し、ブラウザから直接 Anthropic の API に送ります。個人で使う前提の構成です。
- モデルは設定画面で選べます（既定は Claude Opus 5.5）。

## Google Drive 同期（Claude から記録を読めるようにする）
記録するたびに、Google Drive の「毎日の自己管理」フォルダへ自動で JSON を保存します（食事の写真と APIキーは送りません）。
後日 Claude に「Google Drive の『毎日の自己管理_記録.json』を読んで」と頼むと、記録を確認できます。

### 初回設定（1回だけ）
1. https://script.google.com を開き、「新しいプロジェクト」を作ります。
2. 最初からあるコードをすべて消し、このリポジトリの `apps-script/Code.gs` の中身を貼り付けます。
3. アプリの「アプリ設定 → Google Drive 同期」で「合言葉を作成してコピー」を押し、`Code.gs` の `TOKEN = '...'` の中に貼り付けて保存します。
4. Apps Script の右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
5. 「デプロイ」を押し、Google アカウントへのアクセスを許可します。
6. 表示された「ウェブアプリの URL」（`https://script.google.com/macros/s/.../exec`）をアプリの「同期先URL」に貼り付けて「保存」を押します。
7. 「同期済み」と表示されれば完了です。

### 保存されるファイル
- `毎日の自己管理/毎日の自己管理_記録.json` … 最新の記録
- `毎日の自己管理/履歴/記録_YYYY-MM-DD.json` … 日ごとの控え

※「アクセスできるユーザー：全員」にしても、合言葉が一致しない送信は保存されません。
※ iPhone のデータが消えたときは、Drive の JSON を「ファイル」アプリから選んで「アプリ設定 → バックアップ → 読み込む」で戻せます。
