アプリ設定（AI・バックアップ）
AI機能（Gemini API）
写真の栄養分析・体重画面の読み取り・トレーナーの総評・今日の気づきに使います。APIキーは Google AI Studio（aistudio.google.com）で発行します。キーはこのiPhone内にだけ保存され、Google の Gemini API への送信にのみ使います。無料枠の範囲・料金・データの扱いは Google の規約に従います。
キーを保存すると、そのキーで使えるモデルの一覧を Google から取得します。
Google Drive 同期
記録するたびに、Google Drive の「毎日の自己管理」フォルダへ自動で保存します。後日 Claude に記録を読んでもらうときに使います（食事の写真と APIキーは送りません）。設定手順は README の「Google Drive 同期」を参照してください。
バックアップ
記録はこのiPhone内に保存されます。機種変更やデータ消失に備えて、定期的に書き出してください（APIキーは含みません）。
